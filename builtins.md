# Встроенные функции

Ниже перечислены встроенные функции из стандартного окружения интерпретатора.

## Арифметика

- `(+ a b)` -> `int`
- `(- a b)` -> `int`
- `(* a b)` -> `int`
- `(/ a b)` -> `int` (ошибка при делении на ноль)

Все операции требуют два аргумента типа `int`.

## Сравнения

- `(= a b)` -> `bool`
- `(< a b)` -> `bool`
- `(> a b)` -> `bool`
- `(<= a b)` -> `bool`
- `(>= a b)` -> `bool`

Для `< > <= >=` оба аргумента должны быть `int`.
`=` поддерживает сравнение `int`, `bool`, `string`, `nil`.

## Логика

- `(not x)` -> `bool`
- `(and x y)` -> `bool`
- `(or x y)` -> `bool`

Аргументы должны быть `bool`.

## Списки

- `(cons head tail)` -> пара/список
- `(head xs)` -> первый элемент списка
- `(tail xs)` -> хвост списка
- `(isnil x)` -> `true`/`false`

Особенности:
- `head nil` -> runtime error;
- `tail nil` -> runtime error.

## I/O

- `(print x)` -> печатает значение и возвращает `nil`.
- `(readFile path)` -> читает файл и возвращает `string`.
- `(writeFile path content)` -> записывает `content` в файл `path`, возвращает `nil`.

`readFile` и `writeFile` ожидают строковые аргументы и выбрасывают runtime error с контекстом пути при системной ошибке.

## Ленивость

- `(delay x)` -> специальная форма, создает thunk (`#<thunk>`), не вычисляя `x` сразу.
- `(force x)` -> если `x` thunk, вычисляет и кеширует результат; иначе возвращает `x` как есть.

Дополнительно:
- если thunk после `force` даёт функцию, thunk можно вызывать как функцию;
- такие вызовы мемоизируются по набору аргументов (повтор с теми же аргументами берется из кеша).

Обычный паттерн использования:

```lisp
(let add
  (delay (fun (x y) (+ x y)))
  (add 10 32))
```

## Формат значений

- числа/булевы/строки/`nil` печатаются в естественном виде;
- список: `(1 2 3)`;
- dotted pair: `(1 2 . x)`;
- функция: `#<closure>`;
- встроенная функция: `#<builtin>`.
- thunk: `#<thunk>`.
