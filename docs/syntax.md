# Синтаксис языка

`Funky` использует S-expression синтаксис.

## Атомы

- целые: `42`, `-7`, `0`
- булевы: `true`, `false`
- строки: `"hello"` (эскейпы `\n`, `\t`, `\"`, `\\`)
- идентификаторы: `x`, `fact`, `+`, `<=`
- пустой список: `nil`

## Специальные формы

### if

```lisp
(if condition thenExpr elseExpr)
```

Условие обязано вычисляться в `bool`.

### let

```lisp
(let x value body)
```

Связывает имя `x` со значением `value` внутри `body`.

### letrec

```lisp
(letrec f value body)
```

Рекурсивное связывание (обычно для определения рекурсивных функций).

### fun

```lisp
(fun (x y ...) body)
```

Создает функцию и захватывает текущее лексическое окружение (замыкание).

### application

```lisp
(f a b ...)
```

Вызов функции с аргументами.

## Комментарии

`;` до конца строки:

```lisp
; это комментарий
(+ 1 2)
```
