## О проекте

`Funky` — учебный функциональный язык с S-expression синтаксисом и интерпретатором на F#.

Текущий статус:
- этап 1 (лексер, парсер, AST) — завершен;
- этап 2 (интерпретатор, замыкания, рекурсия, базовые builtins) — завершен;
- этап 3 (I/O, базовая ленивость, документация GitHub Pages) — завершен.
