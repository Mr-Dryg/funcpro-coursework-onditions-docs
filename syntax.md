# Синтаксис языка

`Funky` использует S-expression синтаксис.

## Атомы

- целые: `42`, `-7`, `0`
- булевы: `true`, `false`
- строки: `"hello"` (эскейпы `\n`, `\t`, `\"`, `\\`)
- идентификаторы: `x`, `fact`, `+`, `<=`
- пустой список: `nil`

## Специальные формы

### if

```lisp
(if condition thenExpr elseExpr)
```

Условие обязано вычисляться в `bool`.

### let

```lisp
(let x value body)
```

Связывает имя `x` со значением `value` внутри `body`.

### letrec

```lisp
(letrec f value body)
```

Рекурсивное связывание (обычно для определения рекурсивных функций).

### fun

```lisp
(fun (x y ...) body)
```

Создает функцию и захватывает текущее лексическое окружение (замыкание).

### delay

```lisp
(delay expr)
```

Специальная форма. Не вычисляет `expr` сразу, а создает thunk (ленивое значение).

### force

```lisp
(force thunkValue)
```

Встроенная функция. Вычисляет thunk при первом вызове и возвращает кешированное значение при повторных вызовах.

### application

```lisp
(f a b ...)
```

Вызов функции с аргументами.

Если значение функции хранится внутри thunk, thunk можно вызывать напрямую:

```lisp
(let addThunk (delay (fun (x y) (+ x y)))
  (addThunk 10 32))
```

## Комментарии

`;` до конца строки:

```lisp
; это комментарий
(+ 1 2)
```
